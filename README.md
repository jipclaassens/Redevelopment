# Redevelopment

Code for two papers on residential redevelopment and densification in the Netherlands. Each branch belongs to a different paper.

- Branch `RedevPaper`: Claassens, J., Koomen, E., & Rouwendal, J. (2026). Uncovering Dutch residential development processes. Accepted for publication in *Cities*. Working paper: <https://hdl.handle.net/1871.1/196ab657-b809-45f1-b95d-c807d9411568>. If you use this code, please cite this paper.
- Branch `main`: ongoing work on a follow-up paper.
